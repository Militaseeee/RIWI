My Library SPA

Welcome to our virtual library — a clean, fast and intuitive Single Page Application (SPA) where you can explore, manage, and maintain a collection of books effortlessly. Powered by JavaScript, JSON Server, and SPA routing, this tool offers seamless interaction without page reloads.

Main Features

  • View Book Collection: Browse through our catalog of books with details such as title, author, ISBN, and entry date.
  • Add New Books: Easily add a new book using a simple and user-friendly form.
  • Edit & Delete Books (Admin only): Admin users can update or remove book entries as needed.
  • Role-Based Access: Users with admin privileges have extended control over the system.
  • SPA Navigation: All interactions occur dynamically with no page reloads, providing a smooth and responsive experience.

About This Library

This project simulates a lightweight digital library management system. Whether you are a student, teacher, or reading enthusiast, this platform allows you to discover books, register new ones, and manage a simple collection with ease.

Built entirely with vanilla JavaScript, styled using clean CSS, and backed by a simulated REST API (JSON Server), this app is a great example of how front-end development can replicate real-world systems.
