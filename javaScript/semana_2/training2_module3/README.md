# 🧠 Data Management App in JavaScript

Welcome! 👋  
This is a simple interactive web application that lets you explore how information can be organized and shown in a structured way using **JavaScript**.

🌐 **Live demo**: [https://data-management-camila.netlify.app](https://data-management-camila.netlify.app)

---

## 📌 What does this project do?

This app helps you:

- ✅ Add new product categories and items
- ✅ View the list of all products
- ✅ See categories and which products belong to each
- ✅ Display the data in a nice popup window on screen
- ✅ Understand how data is handled behind the scenes using code

It’s like a small system that organizes items into groups, and shows them to you in a clear and visual way.

---

## 💡 Who is this for?

This project was made as part of a **JavaScript learning activity**, but it’s designed so that **anyone** can:

- See how products and categories are displayed
- Add new items through simple questions (prompts)
- Learn the basics of how websites can work with data

It’s ideal for beginners who are curious about how data is stored and shown in web pages.

---

## ✨ Features

- A small collection of products is already created
- You can add new categories and items
- All information appears in a nice table on screen
- Everything also shows in the browser console

---

## 🎮 How to try it

1. Go to the live page: [https://data-management-camila.netlify.app](https://data-management-camila.netlify.app)
2. Open your browser's **console** (press `F12` or `Ctrl + Shift + I`)
3. Follow the questions that appear
4. Click the button on the screen to view your data
