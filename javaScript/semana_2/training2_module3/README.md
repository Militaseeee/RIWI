Entrenamiento
Gestión de Datos con Objetos, Sets y Maps en JavaScript
¡Hola coder!
En este entrenamiento pondrás en práctica tus conocimientos sobre las estructuras de datos avanzadas en JavaScript, específicamente objetos, sets y maps. Estas herramientas te permitirán organizar, almacenar y manipular información de forma más eficiente, mientras aplicas buenas prácticas de programación.

A lo largo de esta actividad, aprenderás a construir una solución utilizando estas estructuras, explorarás formas de recorrer datos empleando bucles como for...in y for...of, y practicarás métodos como forEach() para imprimir resultados de manera clara y descriptiva en la consola.
Objetivo del entrenamiento
El propósito de este entrenamiento es ayudarte a consolidar tu comprensión sobre las estructuras de datos avanzadas en JavaScript, proporcionándote las habilidades necesarias para:
Diseñar y manipular información mediante objetos, sets y maps.
Utilizar bucles y métodos eficaces para recorrer y organizar datos.
Implementar validaciones y pruebas para garantizar la calidad y precisión de los datos manejados en tus programas.
Desarrollo del entrenamiento
Paso 1	Análisis y planificación del problema:
Descarga y lee atentamente la siguiente , y define qué estructura de datos utilizarás en cada etapa: objetos, sets o maps.
Identifica cómo almacenarás los datos y cuáles serán los métodos más eficientes para manipularlos.
Paso 2	Desarrollo del programa:
Crea un objeto llamado productos que almacene 3 productos con las siguientes propiedades:
id (clave única del producto)
nombre (nombre del producto)
precio (valor numérico del producto)
Convierte los datos del objeto en un Set para garantizar que no haya productos duplicados.
Utiliza un Map para agregar información adicional a cada producto. Por ejemplo, añade la categoría de cada producto como clave y el nombre del producto como valor.
Paso 3	Iteración sobre las estructuras de datos:
Usa los siguientes bucles para recorrer e imprimir los datos en la consola:
for...in para listar las propiedades y valores del objeto
for...of para recorrer el Set
Métodos como forEach para recorrer el Map y mostrar las claves y valores en formato descriptivo
Paso 4	Validación y pruebas:
Asegúrate de validar la información del producto para evitar datos incompletos o erróneos.
Realiza pruebas mostrando los siguientes resultados:
Lista completa de productos (a partir del objeto)
Lista de productos únicos (a partir del Set)
Categorías y nombres de productos (a partir del Map)
Paso 5	Entrega del proyecto:
Guarda tu código en un archivo .js llamado gestion_datos.js.
Sube tu archivo a Moodle en formato comprimido (.zip) o proporciona un enlace a un repositorio público en GitHub.
Especificaciones
Incluye comentarios que expliquen cada sección del código.
Utiliza buenas prácticas, como la declaración de variables con let y const, y el uso adecuado de ; al final de cada línea.
Usa los métodos Object.keys(), Object.values(), y Object.entries() para trabajar con objetos.
Implementa for...in, for...of, y métodos como forEach() para recorrer los datos.
