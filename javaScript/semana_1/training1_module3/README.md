# 💬 Interactive Message System

Welcome to the **Interactive Message System**, a simple and interactive web application built with HTML, CSS, and JavaScript. It allows users to enter their name and age to receive a personalized message. Perfect for practicing logic, DOM manipulation, and responsive design in beginner-friendly projects. 🎯

🚀 **Live Demo**:  
👉 [interactive-message-system-camila.netlify.app](https://interactive-message-system-camila.netlify.app/)

---

## ✨ Features

- 📥 User input for name and age.
- 💡 Personalized messages based on age range.
- 🖼️ Clean, responsive and user-friendly interface.
- 🚨 Animated toast notifications with color feedback.
- 🌐 Hosted on **Netlify** for fast and free deployment.

---

## 🧠 Technologies Used

- **HTML5** – Semantic structure.
- **CSS3** – Modern, responsive styling.
- **Vanilla JavaScript** – Interactive logic and DOM manipulation.
- **Netlify** – Hosting and live deployment.
